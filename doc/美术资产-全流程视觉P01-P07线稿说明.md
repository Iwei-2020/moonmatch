## 一、通用线稿规范

| 项 | 规范 |
|---|---|
| 画布基准 | 竖屏 750rpx 宽（等比缩放，逻辑像素 375 宽）；页面左右安全边距 48rpx（= 24px） |

| 色值 Token（冻结，三份资产一致，不得自行改数值） | `--paper` `#FFF8F0`（页面底色 宣纸白）· `--paper-2` `#FDF1E5`（次级底 / 卡片底）· `--ink` `#3A2B2E`（主文字 深墨棕）· `--ink-soft` `rgba(58,43,46,.62)`（次要文字）· `--red` `#C2402F`（朱红：主按钮 / 强调）· `--red-deep` `#A32E22`（朱红深：按下态 / 标题重音）· `--gold` `#D9A441`（金：点缀线 / 角标）· `--line` `rgba(194,64,47,.28)`（红线描边）· `--lock` `#B9AFA6`（锁定态灰：掩码号码）· `--ok` `#3F7A5A`（成功态：解锁成功 / 审核通过）· `--warn` `#C98A2E`（警示态：驳回 / 上限 / 失效） |
| 字体 | 标题：`"Songti SC","LXGW WenKai",serif`；正文：`"PingFang SC","Source Han Sans SC",sans-serif`（字体授权需法务复核） |
| 线描风格 | 细线描：红绳线宽 2px、弯月为金色实心 + 纸色挖空成月牙、窗棂为 `--line` 1px 细线；**不使用写实阴影、不使用渐变描边** |
| 意象使用 | 克制使用：一条红线（可打结）、一弯月、极简窗棂线条；同一画面内意象不超过 2 个 |
| 免责提示字号 | 12px（= 24rpx），**不得低于 24rpx，禁止以更小字号或折叠隐藏**；首页免责为底部常驻 |
| 图标网格与热区 | 图标统一 24 × 24 单位网格，线宽 1.6，圆头端点；展示尺寸 30 × 30px，交互热区 ≥ 44 × 44px（88 × 88rpx） |
| 通用禁止元素 | 二维码、写实人物照片、真人头像占位图、明文联系方式（含完整位数可比数字）、微信/QQ/站外引流字样与图形、「加我微信」类文案、付费 / 充值 / 会员 / 金币 / 置顶元素、广告素材伪装成档案内容 |

**用途**：联系方式字段渲染的唯一出口，承载说明书 §6.4 三态渲染规则。**字幕标注：明文不进入视图层，复制动作直接写入剪贴板。**

#### 9.3.1 线稿

```text
【① 锁定掩码】        【② 已解锁掩码 + 复制】   【③ 失效】
┌──────────────┐   ┌────────────────────┐  ┌──────────────┐
│138****8888  🔒│   │138****8888  [复制] │  │138****8888  ✕│
└──────────────┘   └────────────────────┘  └──────────────┘
│dy_****      🔒│   │dy_****      [复制] │  │dy_****  [复制置灰]│
```

#### 9.3.2 元素清单

| 编号 | 元素 | 内容来源 | 位置与尺寸 | 层级 | 动效 |
|---|---|---|---|---|---|
| ① | 掩码文本 | 说明书 §6.4（保首尾、中间全掩码） | 左侧，17px（抖音号 14px），字距 .10em | 中 | 状态切换 0.2s 变色 |
| ② | 锁 / 开锁 / 失效图标 | 状态图标 | 右侧 15 × 15px（热区外扩至 44 × 44px） | 上层 | 无 |
| ③ | 复制按钮 | 文案「复制」；`tt.setClipboardData` | 右侧，高 28px，`--ok` 实心或置灰 | 上层 | 点击后 toast「已复制，请合规使用」 |
| ④ | 状态底色 | — | 容器圆角 12px：锁定 `#FFFDFA`+`--line`；已解锁 ok 6%；失效 `#F4ECE4` 虚线 | 中 | 无 |

#### 9.3.3 状态与边界

| 状态名 | 表现 |
|---|---|
| ① 锁定掩码 | 掩码 `--lock` 灰；锁图标；无任何可复制入口；不暴露完整位数 |
| ② 已解锁掩码 + 复制 | **仍为掩码展示**（色转 `--ink`）；开锁图标；「复制」按钮可点，点击即写入剪贴板并 toast |
| ③ 失效 | 掩码灰 + 失效图标；「复制」置灰 `disabled`；警示条「该资料已下线」 |

> 边界：**明文永不进入视图层文本节点**（说明书 §6.4）；不写入视图层 `data`、不落 `localStorage`；日志禁止打印明文；同页可同时出现手机号与抖音号两种类型（互斥展示实际只出现 1 条）。

### 9.4 `audit-badge` · 4 态

**用途**：全站统一的审核 / 解锁状态标签。

#### 9.4.1 线稿

```text
 ① ( 待审核 )   gold 系    ② ( 已通过 )   ok 系
 ③ ( 已驳回 )   warn 系    ④ ( 已下架 )   lock 系
```

#### 9.4.2 元素清单

| 编号 | 元素 | 内容来源 | 位置与尺寸 | 层级 | 动效 |
|---|---|---|---|---|---|
| ① | 徽标容器 | 说明书 §4 关键交互组件 | 胶囊，内边距 3/10px，字号 11px（场景放大至 13px） | 上层 | 状态切换淡入 |

#### 9.4.3 状态与边界

| 状态名 | 表现 |
|---|---|
| ① 待审核 | gold 系（色 `#A97A1E`，底 gold 14%，描边 gold 62%）；用于机审处理中 / 人工复核中 |
| ② 已通过 | ok 系（色 `--ok`，底 ok 10%，描边 ok 45%）；用于已登记、已进入匹配池、已解锁 |
| ③ 已驳回 | warn 系（色 `#A9631F`，底 warn 16%，描边 `--warn` 实色）；**必须同时给出驳回原因与「修改重提」入口** |
| ④ 已下架 | lock 系（色 `#7A7069`，底 lock 16%，描边 lock 75%）；用于主动下架与被动隐藏 / 封禁 |

> 边界：颜色语义固定，红 / 绿不得用于暗示优劣或匹配好坏；四态仅作状态标识，不作评分或排名。
